HOW EXTENSIONS WORK AS MODEL SOURCES
═══════════════════════════════════════════════════════════════════════════════

CLAUDE CODE EXTENSION:
  Your IDE sends type information and context to Claude
  Claude uses this to generate more accurate code
  Result: Type-safe, IDE-aware code generation

PYLANCE (TYPE ANALYSIS):
  Analyzes your Python code in real-time
  Infers types of all variables and functions
  Exposes analysis through MCP tools to Claude
  Result: Claude understands your code structure

PYTHON EXTENSION:
  Discovers tests and provides debugging info
  Manages environments and dependencies
  Validates code with linting
  Result: Claude can query and understand tests

GITHUB INTEGRATION:
  Shows repository history and current state
  Tracks issues and pull requests
  Provides project context
  Result: Claude can reference and create issues

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Extensions not showing type hints
  → Wait 10-15 seconds for Pylance to analyze
  → Check Output panel → Python for errors
  → Verify Python interpreter: Settings → Python Path

PROBLEM: MCP servers won't start
  → Check Python: python3 --version
  → Verify dependencies: pip install -r requirements.txt
  → Check logs: tail -f logs/*.log

PROBLEM: Claude can't access tools
  → Ensure servers are running
  → Check: ps aux | grep python3
  → Verify: source .env

PROBLEM: GitHub integration not working
  → Set GITHUB_TOKEN: export GITHUB_TOKEN="ghp_..."
  → Verify token has repo scope
  → Test: python3 -c "from app.services.github import github_service; print(github_service.get_repo_info())"
