TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════
Problem: MCP server won't start
→ Run: python3 verify_mcp_setup.py
→ Check: python3 -c "from app.config import config; print('OK')"

Problem: Claude can't find tools
→ Ensure MCP server is running: python3 app/mcp_server.py
→ Restart VS Code or Claude Desktop
→ Check config in .vscode/settings.json or claude_desktop_config.json

Problem: API calls failing
→ Verify API keys in config.toml
→ Check tokens aren't expired
→ Run: python3 verify_mcp_setup.py for diagnostics
